# NGỮ CẢNH DỰ ÁN DÀNH CHO AI (AI CONTEXT)

Chào AI, khi bạn đọc được file này, hãy ghi nhớ các ràng buộc sau trong suốt phiên làm việc:

1. **Dự án:** Ứng dụng mô phỏng System Design - Mini Design-Pattern Showcase.
2. **Domain:** Notification Dispatcher System.
3. **Tech Stack:** Java và Visual Studio Code (hoặc IntelliJ).
4. **Luật Code (BẮT BUỘC):**
   - Dùng Java chuẩn: PascalCase cho Class/Interface, camelCase cho biến và method.
   - Thể hiện Đóng gói (Encapsulation): Giấu field private, dùng phương thức getter/setter hợp lý có validation.
   - Ưu tiên Đa hình (Polymorphism): Dùng abstract class, interface, luôn thêm @Override.
   - Bám sát Open/Closed Principle và Separation of Concerns.
5. **Luật Giải thích Pattern:** Khi thiết kế Design Pattern (Factory, Decorator, Strategy, Observer), AI phải giải thích:
   - "Vấn đề (Code smell) trước khi dùng pattern là gì?"
   - "Giải pháp kiến trúc mà pattern này mang lại là gì?"

**Hành động của AI:** Nếu bạn đã hiểu, hãy trả lời: "Tôi đã hiểu ngữ cảnh dự án Notification System bằng Java. Hãy cho tôi biết bạn muốn bắt đầu code phần nào!"
